# Simple Calculator with Multiple Screens

**Author:** Shanmukhapriya  
**Project Type:** Android Application (5-Activity Navigation)  

A multi-screen Android Calculator application built with Kotlin and XML featuring five interconnected screens for arithmetic and specialized calculations.

---

## 📌 Features

- **Multi-Activity Architecture**: Seamless navigation across 5 dedicated activities using explicit `Intent`s.
- **Basic & Advanced Calculations**: Standard operations (addition, subtraction, multiplication, division) and dedicated utility calculation screens.
- **Responsive UI**: Clean XML layouts optimized for Android handheld devices.

---

## 🛠️ Tech Stack & Tools

- **Developer**: Shanmukhapriya
- **Language**: Kotlin
- **UI Design**: XML
- **IDE**: Android Studio
- **Minimum SDK**: API 24 (Android 7.0)
- **Target SDK**: API 34 / 35
